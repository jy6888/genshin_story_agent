# 案例：跨来源整理事件

问题：**雪山古国经历了什么？**

这是七题盲测中的 B2，运行配置为 `default-v1.1 / v0.95.2`。本页是人工整理的行为与核查摘要，不是完整模型报告。

Agent 从不同书籍、物品与任务中整理古国建立、毁灭和后续遗迹故事。它需要辨别原文叙述、人物判断与后世传说，并将不同来源放进同一条事件线。

独立冲突核对发现草稿把白树的状态写反，回传相关原文后，最终报告改正。这是本轮有明确草稿与终稿对照依据的一次事实纠正。

最终核查未发现 C1，但仍有两组无充分支持说法：补写人物死亡先后；把物品对应排他地解释为最后三人。另有一项重要隐藏内容遗漏，属于核查者对叙事完整性的判断。

本题使用 297,288 预算 token（未命中输入＋输出）。出处可定位和一次成功纠错，都不能消除其余推断风险。
