# 七题盲测：公开评测摘要

核查日期：2026-11-08。研究对象为《原神》中文固定语料快照上的七道口语考据问题。

本页根据本地执行报告 `blind-test-v1.md` 整理，删去内部任务路径、完整模型请求响应与大段原文。本地原始报告、逐条核查和计量证据由开发者保存，没有随本页分发；读者仅凭公开摘要无法独立重算全部语义指标。

## 设置

- 模型：`deepseek-v4-pro`，thinking enabled、`reasoning_effort=max`，单次输出上限 49,152。
- 框架：Deep Agents / LangGraph；主 Agent 配合对照读者、外部资料审核和隔离的冲突核对角色。
- 版本：B4 为 v0.95.1；B1/B2 为 v0.95.2；B3/B5/B7 为 v0.95.3；B6 为 v0.95.4。主提示与辅助角色提示在此期间保持一致，程序侧有格式、空回复和文件写入修订。
- 语料规模：908 个书籍文件、2,456 个任务文件、5,843 个其他游戏文本文件；书图仅覆盖其中一部分书籍。
- 抽样：每题一次；未完成请求通过保留原记录的恢复继续。核查结果不回馈正式盲测 Agent，金标、评分表和观察点不进入 Agent 输入。
- 核查：Codex 辅助逐条回原文核实、Claude 抽查；社区图谱用于粗略比对，冲突与遗漏仍须回原文确认。没有独立第三方评测或审阅者一致性统计。

C1 指与原文矛盾的定论，按错误处数统计；它不涵盖全部无依据说法，也不是逐条结论准确率。七题合计 C1＝2，未达到零 C1 的质量门槛；另有无充分支持说法 7 组、重要隐藏内容遗漏 2 项，后者属于核查者判断。

两处 C1 分别是未落实后文的身份反转，以及把数代后裔误写成父子。其他问题包括引用不完整、猜测标记缺失、总结丢失限定语、跨时间推断缺桥梁。没有发现 C1 的题也可能存在这些问题。

## 用量口径

452 次已计费请求、451 次完整响应。其中一次可解析空回复照常计费，按规则原样重发一次。

| token 类别 | 合计 |
|---|---:|
| 未命中输入 | 1,550,994 |
| 输出 | 577,002 |
| 预算 token：上述两项之和 | 2,127,996 |
| 缓存命中输入 | 21,563,008 |
| 含缓存输入的原始 token 总和 | 23,691,004 |

预计预算 token 为 2,250,000，上限 4,500,000。预算 token 是本项目的控制口径，不等于免费缓存，也不能直接当作货币金额；本文没有按当前 API 价格追算费用。

## 冲突核对与后续验证

冲突核对占 101 次请求、471,235 预算 token，约为本轮预算 token 的 22.1%。共提交 7 条、程序接受 5 条；其中只有雪山古国一处有明确草稿事实被反向改正的证据，不能把 5 条合格回传都算作事实纠错。

博士题的冲突核对发现了身份反转，但多处行号表达被出处校验器剔除，没有回传。后续 v0.95.5 修复校验器并接续这一题，原身份错误改正；总结却新增一处事件先后错误。此次新增 18 次完整响应、83,228 预算 token，作为独立修复验证记录，不计入原七题结果，也不将其作为重复盲测成绩。

## 能支持什么结论

这组实验说明本地链路能生成可回读原文的研究报告，能在部分问题上纠正题面或草稿，并能保留故障恢复和费用证据；同时暴露了证据整合、时间关系和总结压缩的缺陷。它不能证明稳定零错误、总体准确率、相对 RAG 的提升或生产可用性。
